# Баг-репорты SauceDemo

## Баг 1: Оформление заказа доступно при пустой корзине

**Severity:** Major
**Priority:** High
**Окружение:** Firefox 155.0.1, Windows 10, standard_user

**Шаги воспроизведения:**
1. Открыть https://www.saucedemo.com/inventory.html
2. Убедиться, что корзина пуста
3. Перейти в корзину
4. Нажать «Checkout»
5. Заполнить форму
6. Нажать «Continue» → «Finish»

**Ожидаемый результат:** Система не позволяет оформить заказ с пустой корзиной
**Фактический результат:** Заказ оформляется без товаров


---

## Баг 2: Отсутствует возможность изменения количества товара

**Severity:** Major
**Priority:** High
**Окружение:** Firefox 155.0.1, Windows 10, standard_user

**Шаги воспроизведения:**
1. Добавить товар в корзину
2. Перейти в корзину
3. Попытаться изменить количество

**Ожидаемый результат:** Можно изменить количество товара
**Фактический результат:** Функция отсутствует


---

## Баг 3: Номер заказа не уникален

**Severity:** Major
**Priority:** Medium
**Окружение:** Firefox 155.0.1, Windows 10, standard_user

**Шаги воспроизведения:**
1. Оформить заказ
2. Записать номер
3. Оформить второй заказ
4. Сравнить номера

**Ожидаемый результат:** У каждого заказа уникальный номер
**Фактический результат:** Номера одинаковые
